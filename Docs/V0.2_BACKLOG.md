# V0.2 Backlog（Feature Freeze）

以下内容不得进入 V0.1 关键路径：

- 宗门、公会、聊天、多人在线、跨服。
- 仙侣、宠物、复杂炼丹、复杂炼器、职业系统。
- PVP、排行榜扩展、赛季、交易、拍卖。
- 开放世界、复杂剧情、大型任务系统、复杂社交。
- 后端生产集群、Redis/PostgreSQL 迁移、服务器分片。
- 多章节大地图、复杂技能树、装备洗炼/重铸。
- 正式广告变现与多渠道 SDK（除非 RC 渠道明确要求）。
- 对外在线模式硬化：跨进程持久化战斗结算 session/idempotency intent、账号归属校验、确定性 4xx 与未知结果分流；V0.1 的服务器入口继续仅限 Development。
- 权威在线跨轮回：服务端持久化当前轮回、轮回开始时间与 session 完成轮回，按已完成轮回结算敌人/奖励倍率并补旧库迁移、并发幂等与重连回归；V0.1 离线 RC 继续只在本地执行轮回成长。
- 在线境界失败政策：持久化 300 秒失败冷却，定义 Boss 失败/显式放弃与 75% 材料退款，并提供 Corrupt pending 的受审计恢复流程；V0.1 不扩大离线 RC 范围。

现有 `FutureServiceContracts.cs` 只能保留接口，不得实现上述系统。排行榜虽已有实现，但 V0.1 只保留非关键入口，不再扩展。
