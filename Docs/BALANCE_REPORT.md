# V0.1 10/60 分钟平衡门禁

运行 `Tools/Verification/run-balance-simulation.ps1`，以固定种子 `20260830` 检查真实 JSON 配置。

## 目标阈值

- 10 分钟装备结算：20–25 次；60 分钟：130–150 次。
- 首 Boss：2–4 分钟；首境界突破：3–6 分钟。
- 原型战斗覆盖全部 10 个装备槽；10,000 次抽样中单槽占比 8%–12%。
- Fine / Rare / Epic / Legendary 的目标分布分别约为 40% / 30% / 20% / 10%，容许 ±3 个百分点。
- Boss 每次保底 1 件 Rare–Legendary 装备，奖励池覆盖武器与四个主要防具槽。

## 当前结论

原掉落表只产出武器，无法支撑多槽换装与长期掉落期待，已改为十槽等权原型池；Boss 奖励池扩展为武器、头盔、衣甲、护手和鞋。门禁脚本同时验证所有掉落引用存在，避免配置热调后生成非法物品。

固定种子当前结果：10 分钟 22 件、60 分钟 142 件；品质为 Fine 4017 / Rare 2953 / Epic 1997 / Legendary 1033。十槽计数范围 960–1056，全部位于 8%–12% 门禁内。
